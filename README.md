## Lesson 1: Core Database Concepts

Lesson 1 introduces the fundamental ideas used in database systems.

### Topics Covered

- Databases
- Database Management Systems
- Data abstraction
- Data Definition Language
- Data Manipulation Language
- Conceptual, logical and physical data models
- Entities, attributes and relationships
- Strong and weak entities
- Relationship cardinality
- Entity Relationship diagrams
- Database schemas

- Identifying entities and attributes

- Representing a many-to-many relationship
- Creating database tables with SQL
- Inserting, retrieving, updating and deleting data
