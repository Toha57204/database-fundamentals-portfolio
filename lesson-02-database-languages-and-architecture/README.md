## Key Takeaways

From this lesson I learned:

- DDL is used to define database structures
- DML is used to access and manipulate data
- DCL is used to control user privileges
- TCL is used to control database transactions
- The difference between 1-Tier, 2-Tier and 3-Tier architectures
- The difference between External, Conceptual and Internal schemas
- How mappings connect the three schema levels
